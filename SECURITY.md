# Security policy

DEVos is an early device port. It is not ready for sensitive workloads or public network exposure.

## Reporting a vulnerability

Do not publish details of an unpatched security issue in a public issue. Contact the repository maintainer through GitHub's private vulnerability reporting feature when it is enabled. If private reporting is unavailable, ask the maintainer for a private contact route without including exploit details in the public request.

Include the affected commit or build, the device variant, steps to reproduce, and the impact. Do not include modem NV data, calibration files, private keys, or personal data.

There is no supported production release or response-time commitment yet. The maintainer should update this policy when a private reporting channel and release process are established.
